# Sample SOPs — for pipeline testing only

These short text files are **illustrative, original summaries** of general,
well-known wildland-fire safety practice. They are **not** official Standard
Operating Procedures and must **not** be used operationally.

**Replace this folder with real, licensed regional SOP documents before the
Review-2 final demo.** The RAG ingest step (`python -m ai.rag.ingest`) will index
whatever `.txt` / `.md` files are here.

Files:
- `01_initial_size_up.txt` — first-arriving assessment checklist
- `02_anchor_and_flank.txt` — anchor-point and flanking attack basics
- `03_evacuation_zoning.txt` — downwind evacuation arc sizing
- `04_lces_safety.txt` — LCES (Lookouts / Communications / Escape routes / Safety zones)
- `05_dispatch_staging.txt` — staging area and dispatch coordination
