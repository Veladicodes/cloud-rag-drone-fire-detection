# ADR-003: Data Ingestion and Telemetry Processing Infrastructure

## Status
Approved

## Context
A network of active surveillance drones generates telemetry data streams (GPS, speed, battery, pitch, yaw) at high frequencies (typically 1–5 Hz) along with continuous video/image frames. The backend server must ingest this multi-modal stream from several drones simultaneously, archive historical records for subsequent analytical research, and trigger cognitive processes when a fire is flagged.

---

## Alternatives Considered

1. **Pure Edge Ingestion and Processing**:
   - *Pros*: Eliminates cloud transmission costs; operates in complete network isolation.
   - *Cons*: Cannot coordinate actions across multiple drones; fails to provide centralized situational awareness to ground commanders; constrained by drone battery capacity.
2. **Pure Cloud Ingestion and Processing**:
   - *Pros*: Centralized database simplifies coordination; allows heavy neural networks to run on unlimited cloud virtual machines.
   - *Cons*: High cellular/satellite bandwidth costs; network latency delays detection alerts; system fails if connection drops in deep forest zones.
3. **Hybrid Edge-Cloud Ingestion**:
   - *Pros*: YOLO runs locally on the drone's edge hardware for low-latency detection; telemetry metadata and detection event indicators are transmitted to the cloud via WebSockets/REST; heavy RAG synthesis is offloaded to the cloud.
   - *Cons*: Requires coordinating code versions across both edge devices and cloud endpoints.

---

## Decision
Adopt a **Hybrid Edge-Cloud Processing Ingestion Architecture**. 

---

## Justification & Research Alignment
- **Bandwidth Efficiency**: Streaming high-definition video continuously from forest boundaries to the cloud is cost-prohibitive. By running YOLOv8 at the edge, only low-overhead metadata alerts and brief snapshot frames are sent when an incident occurs.
- **Fail-Safe Operation**: If a drone loses its cellular or satellite link, edge detection continues locally, logging events and telemetry locally. The data syncs to Azure SQL and Blob Storage once the connection is restored.
- **Global Context Consolidation**: The FastAPI backend acts as a central aggregator, enabling the React frontend to present a unified view of all active drones and coordination plans.
