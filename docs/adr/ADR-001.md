# ADR-001: Object Detection Model Framework

## Status
Approved

## Context
Real-time, early-stage forest fire detection from drone video streams demands highly localized, low-latency, and robust object detection. Early fire events are marked by small flame pixels or amorphous, diffuse smoke columns that are easily obscured by the forest canopy. The detection model must run either directly on resource-constrained drone edge hardware (e.g., NVIDIA Jetson boards) or be processed rapidly in the cloud with minimal frame queue latency.

---

## Alternatives Considered

1. **Standard Convolutional Image Classifiers (e.g., ResNet-50, EfficientNet-B4)**:
   - *Pros*: Simple training, robust classification.
   - *Cons*: Fails to provide spatial localization (bounding boxes) of the smoke or fire within the video frame.
2. **Vision Transformers (ViTs) for Object Detection (e.g., DETR)**:
   - *Pros*: State-of-the-art spatial relationship learning; handles global context extremely well.
   - *Cons*: Extremely high computational complexity, slow inference rates on edge devices, and requires massive training datasets to converge.
3. **YOLO (You Only Look Once) Framework (v8/v9)**:
   - *Pros*: Single-stage detection enables real-time frame rates ($\ge 30$ FPS); anchor-free head increases accuracy for amorphous objects like smoke; decoupled architecture separates classification and regression tasks.
   - *Cons*: Lower accuracy on very small objects compared to multi-stage detectors (like Faster R-CNN), though mitigated by feature pyramid networks (PANet/FPN).

---

## Decision
Select **YOLOv8/v9** as the primary object detection framework, implemented in PyTorch. 

---

## Justification & Research Alignment
- **Real-Time Inference**: YOLO's single-pass neural network architecture is mathematically optimized for speed, producing inference times under 30ms per frame. This meets the criteria for immediate hazard detection.
- **Edge Deployment**: The availability of compressed sub-variants (YOLOv8-Nano/Small) allows compiling to TensorRT engines, running efficiently on Jetson Orin edge boards without depleting drone battery capacity.
- **Localization Capability**: Bounding boxes provide GPS telemetry coordinate estimates of the fire by translating image pixels to earth coordinates using drone altitude and camera pitch calculations.
