# ADR-002: Emergency Response Cognitive Engine

## Status
Approved

## Context
When a drone detects a forest fire, the system must generate a localized, actionable incident response plan. This plan must account for local weather (wind heading, humidity, temperature), drone coordinates, terrain parameters, and government Standard Operating Procedures (SOPs). Because this is a high-consequence safety framework, the response recommendations must strictly adhere to approved regulations and avoid LLM hallucinations.

---

## Alternatives Considered

1. **Rule-Based Decision Trees & Expert Systems**:
   - *Pros*: Completely deterministic; zero hallucination risk.
   - *Cons*: Highly rigid; fails to generate natural language instructions or adapt to complex, multi-factor environmental contexts.
2. **Fine-Tuning a Large Language Model (e.g., Llama-3, GPT-4)**:
   - *Pros*: Customizes the model's tone and domain vocabulary to wildland fire terminology.
   - *Cons*: Extremely expensive to train; hard to update when SOP guidelines are modified; does not eliminate hallucination risks; cannot cite specific source paragraphs.
3. **Retrieval-Augmented Generation (RAG)**:
   - *Pros*: Dynamically injects relevant SOP document chunks into the LLM context; allows updating the guidelines instantly by regenerating the vector index; supports direct citation of source files; keeps the LLM grounded in real-world facts.
   - *Cons*: Increases response latency (retrieval step + generation step); dependent on vector embedding accuracy.

---

## Decision
Utilize a **Retrieval-Augmented Generation (RAG)** pipeline orchestrated via **LangChain** and indexed with a **FAISS** vector database.

---

## Justification & Research Alignment
- **Safety and Accountability**: RAG enforces a closed-book system where the LLM is instructed to answer *only* based on the retrieved context. If the database lacks context, the model reports a fallback flag, avoiding dangerous advice.
- **Dynamic Adaptability**: SOP manuals and weather conditions change frequently. Replacing a text document in the `data/knowledge-base/` folder and rebuilding the FAISS index updates the AI's response logic instantly, without retraining.
- **Traceability**: The UI can display the retrieved document source segments alongside the generated response plan, giving dispatchers a way to verify the plan's alignment with regulation.
