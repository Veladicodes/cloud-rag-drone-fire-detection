# Project Timeline

This document outlines the week-by-week semester schedule for the research project, mapping weekly goals to specific team tasks.

---

## Weekly Schedule

### Week 1: Literature Review & Sourcing
- **Goal**: Research historical drone classification models and RAG frameworks.
- **Tasks**: Source relevant academic publications (5 per researcher, 15 total) and draft initial paper summaries.

### Week 2: Literature Synthesis & Gap Identification
- **Goal**: Identify core research gaps in emergency response coordination.
- **Tasks**: Compile the literature survey and draft the research gap analysis.

### Week 3: Project Scope & Core Objectives
- **Goal**: Define primary and specific research objectives.
- **Tasks**: Finalize research questions (RQ1-3) and draft the project objectives.

### Week 4: Dataset Acquisition & Partitioning Study
- **Goal**: Study FLAME and FireNet dataset structures.
- **Tasks**: Download datasets, verify annotations, and define target training splits.

### Week 5: Preprocessing & Augmentation Strategy
- **Goal**: Draft the image transformation pipeline.
- **Tasks**: Define perspective shifts, color adjustments, and synthetic smoke mask parameters.

### Week 6: System Component Design & UML Mapping
- **Goal**: Model component relationships and data flows.
- **Tasks**: Draft component and sequence diagrams using Mermaid code.

### Week 7: Architecture Decision Records (ADRs)
- **Goal**: Document key architectural choices.
- **Tasks**: Author ADR-001, ADR-002, and ADR-003, detailing alternatives and justifications.

### Week 8: Backend & Cloud Security Routing
- **Goal**: Define backend and cloud network architectures.
- **Tasks**: Map API endpoints, design Azure SQL schemas, and draft VNet subnets.

### Week 9: RAG Ingestion & Prompt Modeling
- **Goal**: Model RAG retrieval and prompting strategies.
- **Tasks**: Define document chunk sizes, FAISS vector index logic, and system prompt constraints.

### Week 10: Testing Strategy & Evaluation Design
- **Goal**: Define testing parameters and metrics.
- **Tasks**: Plan simulated tests for YOLO accuracy, network latency, and RAG consistency.

### Week 11: Integration Planning & Evaluation Matrix
- **Goal**: Map components to validation gates.
- **Tasks**: Create expected metrics tables and map individual team responsibilities to gates.

### Week 12: Review-1 Compliance Audit & Packaging
- **Goal**: Verify repository readiness and prepare presentation materials.
- **Tasks**: Compile the Review-1 Compliance Report, verify folder completeness, and draft presentation slide outlines.
