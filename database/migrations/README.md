# Migrations

For the local prototype the schema is created directly from the SQLAlchemy
models via `Base.metadata.create_all` (`backend/core/db.py::init_db`), so a fresh
`local.db` is one command.

For the real Azure SQL deployment this folder will hold **Alembic** revision
scripts:

```
pip install alembic
alembic init database/migrations
# set sqlalchemy.url from DATABASE_URL, target_metadata = backend.core.db.Base.metadata
alembic revision --autogenerate -m "initial schema: drones, telemetry, incidents, response_plans, alerts"
alembic upgrade head
```

The models already use portable column types only, so the autogenerated initial
migration will apply unchanged to Azure SQL.
