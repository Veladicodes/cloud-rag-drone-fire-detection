# Frontend Directory

## 1. Purpose
This folder contains the operator dashboard web interface codebase, built using React and TypeScript.

---

## 2. Future Contents
- `src/components/`: Map modules, status widgets, and RAG checklist displays.
- `src/hooks/`: WebSocket hooks for streaming live telemetry.
- `src/services/`: HTTP client configurations to connect with the backend API.
